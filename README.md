
# Text Analyzer

## Description
Text Analyzer is a beginner-friendly Python project
that analyzes a sentence or paragraph and displays useful information about the entered text.
It helps beginners understand string operations and basic text processing in Python.

## Features
- Counts total characters.
- Counts total words.
- Counts uppercase letters.
- Counts lowercase letters.
- Counts digits.
- Counts spaces.
- Counts vowels.

## Concepts Learned
- Variables and strings
- User input and output
- String methods (`split()` and `count()`)
- `len()` function
- Loops and conditional statements
- Character counting and text processing

## Future Improvements
- Count consonants.
- Find the most frequently used word.
- Count punctuation marks.
- Display the longest word.
- Add more text analysis features.
